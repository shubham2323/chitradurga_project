# Steps to run the code:
## 1. Install the libraries from the requirements.txt file.
## 2. Load the workflow.ipynb file in jupyter.
## 3. Run the first cell to start the EE export tasks, which will export the data to google drive, then download the raster files from google drive to 'chitradurga_raster' folder, and the 'chitradurga_gt_training_features_2026.csv' csv file directly to the same directory as the workflow.ipynb file.
## 4. Once the download is completed, run rest of the cells to generate final visualization Maps and stats.
